# Security Policy

This repository is currently research, documentation, and design material
(Markdown). It does not yet ship executable code with a meaningful attack
surface. As the design guidelines, components, and Claude skill mature, this
policy will grow with them.

## Reporting a vulnerability

Please **do not** open a public issue for security reports.

Use GitHub's private reporting instead:

1. Go to the [**Security** tab](https://github.com/draaujpeg/solana-uiux-onboarding-kit/security) of this repository.
2. Click **Report a vulnerability**.
3. Fill in the details.

This opens a private channel visible only to the maintainers. No email is
required. We'll acknowledge your report and keep you updated on the fix.

## Scope

Since the kit is documentation-first today, relevant reports include, for
example:

- Malicious or misleading guidance that could put onboarding users at risk
  (e.g. advice that weakens self-custody or key safety).
- Vulnerabilities in any code that lands under `design-guidelines/` or
  `skill/` as those pillars are built.

Thank you for helping keep the kit and its users safe.
